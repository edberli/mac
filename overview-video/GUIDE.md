# 《Wait What》頻道影片製作指南（交畀本機 Claude Code）

呢份係第一集（EP01：「太空睇唔睇到長城」）做完之後總結嘅**完整做法**。之後每一集都照呢份做。
第一次接手，請由頭睇到尾，再睇 `HANDOFF_MANDARIN.md`（目前未完成嘅工作）。

---

## 1. 頻道目標同觀眾

- 頻道名：**Wait What**（片頭：`assets/brand/wait-what-intro-5s.mp4`）
- 觀眾：英文市場為主；同一條片再加**普通話音軌**同**中文字幕**照顧華語觀眾。
- 目的：新頻道，盡快達到 YouTube 盈利資格（1,000 訂閱 + 12 個月內 4,000 小時長片觀看時數）。
- 片長：**每集 3 至 5 分鐘、橫向 1920×1080**（16:9）。直向或正方形、3 分鐘以下會被當成短片，時數唔計。
- 每集**獨立完整**，唔好做「上下集」；邊集受歡迎先做續集。

## 2. 內容結構（已驗證有效）

1. **第一秒就係鉤子**：直接用最震撼嘅畫面加一條推翻常識嘅問題（EP01：喺太空站問「長城喺邊？」）。
2. **短短交代背景**：快速剪接幾個世界地標（自由神像、金字塔、長城），等內容有環球感。
3. **第二個懸念**：「呢個仲唔係最奇怪嘅事」。
4. 片名畫面 → **Wait What 片頭**（固定放喺鉤子之後）→ 倒敘「EARLIER」開始正片。
5. 正片：**一步步行遠／升級**，每段一個推翻常識或者具體數字（年份、距離、比例），用圖解講。
6. 情緒高位：真實人物故事（例如 90 歲上太空嘅演員）。
7. 結尾：連結返觀眾日常生活（「下次為小事唔開心，諗吓嗰一點」）+ 片尾。

寫作規則：
- 對白用**兩個角色問答**，唔用旁白；年輕人代觀眾發問，AXIS 負責答。
- **每個事實都要查證**，唔肯定嘅就改寫成肯定得到嘅講法（例如「至少 1754 年已經有人寫低」）。
- 唔好抄任何現有影片嘅對白、角色或者設定；只學結構。

## 3. 畫風同角色（用戶已確認，唔好改）

- **畫風：電影感剪影**。日落色調（深紫→橙→金）、層層山脈有霧氣、人物係黑色剪影加邊光、有塵埃同顆粒感、慢鏡推進。
  - 用戶**唔鍾意**：卡通可愛風格、大頭細身比例、兒戲感。
- **太空場景一律喺「太空站觀景艙」入面**：大觀景窗（三格、斜角窗框）、窗邊長凳、艙內面板同指示燈、可以向上收起嘅防護閘門。人物**唔可以無端端坐喺半空**。
- **地球同星空用真實相片**：three.js 立體地球（`render/lib/earth.js`），Solar System Scope 8K 圖（CC BY 4.0）。地球每個鏡頭只計一次再重用（快好多）。
- **人類**：年輕男性，側面剪影，連帽衫、波鞋；手臂用兩節關節計算（肩→手肘→手），手搭膝頭。
  - **曾經出錯**：手臂由肩膊後面畫落去、部件重疊穿窿。畫完一定要放大檢查手、手臂、膝頭。
- **AXIS**：懸浮人工智能機械人，深色外殼、幼長青色發光眼、頭上有**軌道光環**（後半圈要被頭遮住，前半圈喺前面）、雙手分離浮喺身邊。
- **解說圖**：青色發光線條（`#7ff3ff`），好似 AXIS 投射出嚟嘅資料。
- **字幕**：畫面預設**唔內嵌**，改用 SRT 字幕檔上載（`tools/subtitles.py`）。EP01 例外，已經內嵌英文字幕。

## 4. 配音（MiniMax，國際版 api.minimax.io）

- 金鑰：環境變數 `MINIMAX_API_KEY`。**絕對唔可以寫入任何檔案或者資料庫**。
- 地址：金鑰前綴 `sk-cp-` 係中國區帳戶，要加環境變數 `MINIMAX_BASE=https://api.minimaxi.com`；連國際版會出「invalid api key」（2026-11-05 實測）。
- 英文（已確認）：
  - 人類：`English_FriendlyPerson`
  - AXIS：`English_Gentle-voiced_man`，加 `robot` 電子效果。用戶試過輕版（`robot_light`），**覺得原本較重嘅好啲**。
- 重點句子加情緒（劇本裏面每句 `"emotion"`：happy、sad、surprised、neutral 等）。
- **注意編號**：用戶講「第 5 號、第 9 號」係指 `--list` 清單入面**只計男聲**嘅排序（第 5 號就係 Gentle-voiced man）。唔肯定就問名。
- 有感情嘅讀法會比較長，換聲之後要**重新排時間軸再渲染**，唔好硬塞（會重疊或者太快）。
- 其他選擇：`tools/tts_kokoro.py`（免費、離線，但冇咁有感情）、`tools/tts.py`（Piper，太悶，唔好用）。

## 5. 製作流程（指令）

第一次：

```bash
cd overview-video && tools/setup.sh
```

每一集：
1. 寫劇本 `script/epXX_*.json`（對白 `say`、停頓 `pause`、場景標記 `mark`、音效 `sfx`、插入片頭 `inserts`）。
2. 配音：`python3 tools/tts_minimax.py script/epXX_main.json build/epXX_main`
3. 時間軸：`python3 tools/timeline.py script/epXX_main.json build/epXX_main`
4. 畫面：寫 `render/epXX_*.html`（參考 `render/ep01_intro.html`、`render/ep01_main.html`，重用 `render/lib/kit2d.js` 同 `render/lib/earth.js`）。
5. **先渲染十幾格做縮圖總覽檢查**，冇問題先渲染全片：`node tools/render.js render/epXX_main.html build/epXX_main 100,500,900`
6. 全片：`node tools/render.js render/epXX_main.html build/epXX_main`
7. 混音：`python3 tools/mix.py build/epXX_main`
8. 合成：見 `tools/build.sh`；插入片頭：`tools/assemble.py`；多段合併：`tools/join.sh`
9. 字幕：`python3 tools/subtitles.py epXX epXX_intro epXX_main`（要先準備 `script/epXX_zh.json` 中文翻譯）
10. 每集完成後將 `build/<段>/timeline.json` 複製去 `script/timelines/`，普通話配音要用。

速度參考（雲端 4 核心）：2D 為主嘅畫面每分鐘大約 125 格；3 分鐘片大約 30 至 40 分鐘。喺 Mac 用顯示卡會快好多（`GPU=1` 環境變數會唔用軟件繪圖）。

## 6. 交片前檢查清單

- [ ] 縮圖總覽睇晒每個場景：人物手腳、AXIS 光環遮擋、地球、字幕長度（太長會自動拆兩行）
- [ ] 1920×1080、每秒 30 格、橫向；片長 3 分鐘以上
- [ ] 音量大約 −16 LUFS，峰值唔超過 −1.5 dBTP（`mix.py` 已自動處理）
- [ ] 說明欄有素材出處（`assets/textures/CREDITS.md`）同人工智能配音聲明
- [ ] 標題、說明欄、章節時間、標籤、縮圖 A/B（參考 `publish/ep01_youtube.md`）

## 7. 用戶偏好（好重要）

- **回覆用繁體中文（廣東話）**，唔好中英夾雜；英文名詞要附中文解釋。
- 每次回覆最後加**日期同時間（新加坡時間）**；長答案加「簡單易明版」。
- **要快、要慳錢**：最大程度重用素材；唔好為細節重新渲染全片；有字幕就照用，唔好為字幕重做。
- 要花長時間或者額外費用嘅改動（例如重新渲染、換配音），**先講清楚時間同代價再做**。
- 估時間要老實，估錯要即刻講。早啲畀預覽（縮圖、試聽）。
- 用戶會**一次過**講晒要改嘅地方，盡量一次改完。

## 8. 上載

- 雲端或者本機都冇 YouTube 上載權限，由用戶喺 YouTube Studio 手動上載（大約 5 分鐘）。
- 普通話：用 YouTube「多語言音軌」功能（2025 年 9 月起開放畀所有創作者）上載 `publish/<ep>.audio.zh.m4a`，再上載中文 SRT 字幕。
